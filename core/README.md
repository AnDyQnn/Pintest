# core/ — стековый движок аудита (общий)

Рабочая копия движка сканирования/отчётности, которой пользуются агенты и хост. В отличие от
эталонного [`../pintest/audit.py`](../pintest/) (его не трогаем), `core/` можно править свободно.

## Что внутри
| Файл | Ответственность |
|---|---|
| `auditor.py` | Собственно проход по хостам: порты + CVE (через nmap NSE `vulners`), запись `results.jsonl`. |
| `targets.py` | Канонизация «грязного» списка целей: валидация, развёртывание CIDR/диапазонов, дедуп, отсев мусора. |
| `reporting.py` | Сборка сводного отчёта из результатов (md/html/csv/json), инкрементально (`--resume`). |

## Роли в системе
- **агент** запускает `core.auditor` по своему чанку и отдаёт `results.jsonl`;
- **хост** (`backend/orchestrator.py`) сливает результаты и пересобирает отчёт после каждого чанка
  через `core.reporting`;
- **хост** (`backend/targets.py`) чистит список целей через `core.targets`.

Только stdlib + внешний `nmap` — никаких «лабовых» веток, поведение через параметры.
