# host/frontend/static/ — статика вебки

Файлы, которые nginx отдаёт браузеру. Подробности и роль каждого — в родительском
[`../README.md`](../README.md).

Коротко: `index.html` (разметка) · `app.js` (логика/WS/консоль/лут/отчёт) ·
`topology.js` (живой граф сети с pan/zoom) · `fx.js` (фон/иконки) · `style.css` (тёмная тема) ·
[`vendor/`](vendor/) (xterm.js — консоль, локально/офлайн).
