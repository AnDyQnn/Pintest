# host/frontend/ — вебка (nginx + статика)

nginx отдаёт статику дашборда и проксирует `/api/*` на backend (HTTPS, самоподписанный серт).

## Структура
| Файл | Что это |
|---|---|
| `nginx.conf` | reverse-proxy на backend (`/api/`, `/api/live` WS) + отдача статики. |
| `entrypoint.sh` | Генерация самоподписанного сертификата на старте. |
| `Dockerfile` | nginx:alpine + статика. |
| `static/index.html` | Разметка вебки (вкладки: обзор, агенты, цели, скан, консоль, отчёты, эксплуатация…). |
| `static/app.js` | Логика: авторизация, вкладки, живой статус (WS), консоль, лут, нативный отчёт. |
| `static/topology.js` | Живой граф сети (force-directed) с pan/zoom и анимацией процессов. |
| `static/fx.js` | Анимированный фон + SVG-иконки + брендинг. |
| `static/style.css` | Тёмная тема. |
| `static/vendor/` | Вендоренные библиотеки (xterm.js для консоли) — без CDN, работает офлайн. |

## Живая топология (`topology.js`)
Сеть рисуется как **граф**: HOST (центр) → агенты → цели. Узлы расталкиваются силовой
моделью (масштабируется на много устройств), подписи разводятся. Колесо — масштаб, тяни —
двигать, 2×клик — сброс. Статусы целей цветом, рокировка/недостижимость/захваты — анимациями.

## Консоль
Вкладка «Консоль» — полноценный bash на ноде через туннель (xterm.js), можно несколько вкладок.
Данные идут `браузер → backend → агент` (см. `backend/app/console.py`).
