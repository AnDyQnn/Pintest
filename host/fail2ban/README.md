# host/fail2ban/ — защита хоста от перебора SSH

**Это НЕ VPN/Amnezia** (тот в [`../vpn/`](../vpn/)). fail2ban — отдельный слой хардненинга:
следит за логом sshd и **банит IP** после нескольких неудачных входов, закрывая сервер от
внешнего брутфорса (одна из мер «окопаться»).

## Файлы
| Файл | Что это |
|---|---|
| `jail.local` | Политика бана: `maxretry=5`, `findtime=10m`, `bantime=1h`, jail `[sshd]`. |
| `Dockerfile` | Демонстрационный контейнер fail2ban для лабы. |

## Где реально работает
- **В лабе** — как отдельный контейнер (демонстрация, что слой есть).
- **На реальном сервере** — `host/install.sh` ставит fail2ban **на сам хост** и копирует
  сюда `jail.local`, плюс поднимает `ufw` (firewall). То есть в проде это не контейнер, а
  системный сервис хоста.
