# agent/scripts/ — исполняемые скрипты ноды

Скрипты, которые запускает хост (по SSH при provisioning) или сама нода (agent_api).

| Скрипт | Когда и что |
|---|---|
| `apply-awg.sh` | Поднять клиентский туннель AmneziaWG из конфига, вброшенного хостом (`awg-quick up awg0`). После успешного handshake **взводит dead-man** (флаг `armed`). |
| `self-destruct.sh` | Необратимое самоуничтожение проекта на ноде: туннель вниз, стирание ключей/конфигов/результатов/кода. Строго в пределах проектной папки. |
| `setup-exploiter.sh` | Донастройка ноды под роль `exploiter` (доустановка утилит/модулей). |
| `apply-update.sh` | Применение обновления, доставленного хостом по SSH (разворачивает бандл, мягко перезапускает API). |

Все — идемпотентны и рассчитаны на запуск от root в контейнере/на сервере.
