# agent/ — удалённая нода (exit node)

«Руки» системы: агент стоит **в сети целей**, хост — нет. Один Docker-образ `pintest-agent`,
всё поведение — через ENV (никаких «лабовых» веток). Хост подключает ноду по SSH, вбрасывает
VPN-ключ и поднимает туннель — вручную настраивать ноду не нужно.

## Развёртывание на реальном сервере
```bash
git clone <repo> pintest && cd pintest/agent
sudo ./install.sh      # ставит образ/зависимости; дальше ноду подключает ХОСТ из вебки
```

## Структура
| Папка / файл | Что это |
|---|---|
| [`agent_api/`](agent_api/) | FastAPI ноды (:9101, только по туннелю): чанки, роли, эксплуатация, консоль, dead-man. |
| [`awg-client/`](awg-client/) | Клиентская сторона AmneziaWG (конфиг вбрасывает хост). |
| [`scripts/`](scripts/) | Скрипты ноды: поднять туннель, самоуничтожение, донастройка exploiter, обновление. |
| [`state/`](state/) | Runtime-состояние (роли/джобы/лут) на volume. |
| `Dockerfile` | Образ ноды (nmap + NSE vulners, python, sshd для provisioning, утилиты туннеля). |
| `entrypoint.sh` | Старт: sshd (для первичного provisioning) + agent_api. |
| `install.sh` | Bootstrap ноды на реальном сервере. |

## Роли и безопасность
- `scanner` (по умолчанию) — сканирует; `exploiter` — назначается вручную, идёт донастройка.
- **dead-man switch**: при потере связи с хостом дольше `DEADMAN_TIMEOUT` нода **самоуничтожается**
  (стирает проект у себя, строго в пределах своей папки). Взводится только после успешного
  provisioning. ⚠️ Поэтому не держи ноду без хоста дольше таймаута — сотрётся.
