# Changelog

Формат — по [Keep a Changelog](https://keepachangelog.com/ru/), версии — [SemVer](https://semver.org/lang/ru/).
Версия продукта задаётся через `PINTEST_VERSION` (дефолт в `config.py`) и видна в вебке/health/отчётах.

## [0.2.0] — 2026-08-21

### Добавлено
- **Граф сети (достижимость + рокировка).** Топология стала настоящим графом HOST→агенты→цели:
  силовая (force-directed) раскладка с авто-вписыванием под размер карты, pan/zoom, авторазведение
  подписей, анимация процессов. Расчёт достижимости (BFS), авто-**рокировка** маршрута цели на
  другого онлайн-агента при выпадении исходного, панель «точек отказа». Роуты `/api/topology`, `/api/graph`.
- **Консоль узлов.** Полноценный bash на ноде из вебки через туннель (PTY на агенте + проброс
  через хост, эмулятор xterm.js локально/офлайн), несколько вкладок. `/api/console/*`.
- **Лут и лут-отчёт.** Просмотр реального содержимого закреплений (shell/RCE-вывод, флаг, маркер,
  лог) карточками; отдельный лут-отчёт `/api/loot/report.{md,html,json}`.
- **Отчёты в тёмной теме.** Отчёт аудита рендерится нативно в вебке (сводка + severity + по хостам)
  вместо белого iframe; выгрузка md/html/csv/json сохранена.
- **Автоопределение адреса хоста.** `AWG_ENDPOINT` теперь опционален — определяется сам
  (внешний сервис → IP интерфейса); тумблеры `AWG_NO_EXTERNAL`, `AWG_PUBIP_URLS`.
- **Полигон устройств** `lab/polygon.sh` — автономный консольный скрипт: N разнотипных устройств
  (web/СУБД/камера/принтер/роутер/telnet/SCADA/VoIP), связанные + изолированные.
- **Документация.** README в каждой папке; обновлены `docs/architecture.md`, `docs/usage.md`, `README.md`.

### Изменено
- Редизайн обзора: честные KPI вместо фейковых спарклайнов, панель достижимости/точек отказа.
- Вынесены в ENV: `LIVE_INTERVAL`, `TUNNEL_NET` (vpn); версия поднята до 0.2.0.

## [0.1.0] — 2026-08-17

### Добавлено
- Базовая распределённая система: control plane (backend/frontend/postgres/vpn/fail2ban),
  агент-ноды по AmneziaWG, оркестрация сканов с failover, отчёты (md/html/csv/json), DIFF,
  бэкапы, две механики обновлений, модульная CTF-эксплуатация (check/capture с гейтом
  подтверждения), dead-man switch, тестовая лаба в Docker.
- Эталонный аудитор `pintest/audit.py` (standalone, только stdlib).
