# Pintest — учебный аудитор сети

`audit.py` — сетевой аудитор в **одном файле на Python** (только стандартная библиотека,
внешних пакетов не нужно). За **один прогон**: разведка целей → живые хосты → проба
портов → глубокий скан (TCP/UDP + NSE) → поиск CVE → готовые отчёты в 4 форматах.

Оценку критичности (CVSS), риск и рекомендации проставляет автоматически. Обёртка над
`nmap`: читает его XML-вывод, ничего не эксплуатирует — только выявление и отчёт.

> ⚠️ **Только авторизованное использование.** Запускать можно **исключительно** по целям,
> на которые есть разрешение: свой стенд / VPS или scope учебного задания. Сканирование
> чужой инфраструктуры незаконно. Списки реальных целей в репозиторий не коммитятся
> (см. `.gitignore`).

---

## Возможности

- **Единый конвейер** за один запуск: список → discovery → порты/сервисы → уязвимости → отчёт.
- **Поиск CVE по версиям сервисов** — NSE-скрипт `vulners` (онлайн-база) + категория `vuln`.
- **4 формата отчёта**: Markdown, интерактивный HTML (фильтры + сворачиваемый список CVE,
  живой поиск, ссылки на NVD), CSV, JSON.
- **Проба портов (префлайт)** — перед сканом отсеивает порты, которые режет провайдер/VPN
  (`filtered`), и показывает их; сканирует только реально доступные.
- **Фоновый режим (демон)** с живым онлайн-статусом (3 прогресс-бара: общий / этап / чанки).
- **Пауза и продолжение** (`--resume`) — прервать и продолжить с последнего места.
- **IPv4 и IPv6**, разворачивание CIDR/диапазонов, валидация и чистка списка.
- **Управление скоростью/нагрузкой**: тайминг `-T`, параллелизм `-j`, `--no-udp`/`--no-tcp`.
- **Отчёт растёт по ходу** — пересобирается после каждого чанка.

## Требования

- `python3` (3.8+)
- `nmap` (сканер + NSE-скрипты)
- интернет — желателен: скрипт `vulners` тянет CVE из базы vulners.com

## Установка

```bash
# поставить nmap и прописать алиасы (audit / astatus / awatch / astop):
python3 audit.py --install
source ~/.bashrc
```

## Быстрый старт

```bash
# 1. список целей — по одному адресу на строку (пример: examples/targets.sample.txt)
nano targets.txt

# 2. запуск
python3 audit.py targets.txt

# 3. отчёт — в папке audit_<дата>/:
#    report.md  ·  report.html (открыть в браузере)  ·  findings.csv / .json
```

Фоном, спокойно для VPS:
```bash
python3 audit.py -d -T3 -j 2 --no-udp targets.txt   # запустить в фоне
python3 audit.py --status-live                       # смотреть онлайн (Ctrl+C — выйти, демон продолжит)
python3 audit.py --stop                              # остановить
```

## Ключи (кратко)

| Ключ | По умолчанию | Что делает |
|------|:---:|------------|
| `--top N` / `-A` / `-p СПИСОК` | топ-100 | выбор портов (топ-N / все 65535 / конкретные) |
| `--no-udp` / `--no-tcp` | TCP+UDP | ограничить протокол |
| `-T 0..5` | `4` | тайминг nmap (0 — тихо, 5 — агрессивно) |
| `-j N` | `4` | сколько nmap параллельно (нагрузка ×N) |
| `--Pn` | выкл | пропустить разведку — все цели считать живыми |
| `--no-preflight` | проба вкл | не пробовать порты перед сканом |
| `-d` | выкл | запустить в фоне (демоном) |
| `--status` / `--status-live` / `--stop` | — | статус фонового прогона / стоп |
| `--resume [папка]` | — | продолжить прерванный прогон |
| `--install` / `--uninstall` | — | nmap + алиасы / убрать алиасы |

Полный справочник со всеми деталями — в **[docs/audit-manual.md](docs/audit-manual.md)**.

## Что на выходе (`audit_<дата>/`)

| Файл | Что это |
|------|---------|
| `report.md` | отчёт по хостам: порты, CVE/CVSS, автооценка (критичность/риск/рекомендация) |
| `report.html` | интерактивный отчёт: список всех CVE, фильтры, поиск, ссылки на NVD |
| `findings.csv` / `findings.json` | все находки таблицей / в JSON |

Образец всех форматов — в папке [`examples/sample-report/`](examples/sample-report/).

## Как работает (этапы)

1. Чистка и валидация списка, деление на IPv4 / IPv6.
2. Host discovery — кто живой.
3. *(2.5)* Проба портов на выборке — отсев фильтрации провайдера/VPN.
4. Порты и сервисы: TCP (`-sV`) + UDP (топ-50), чанками, параллельно.
5. Поиск уязвимостей (NSE `vuln,vulners` + enum) — только по хостам с открытыми портами.
6. Сборка отчётов (md · html · csv · json).
