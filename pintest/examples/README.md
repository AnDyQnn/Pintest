# pintest/examples/ — примеры для эталонного аудитора

Примеры входа и выхода для standalone-аудитора [`../audit.py`](../audit.py).

| Файл / папка | Что это |
|---|---|
| `targets.sample.txt` | Пример «грязного» списка целей (CIDR/диапазоны/мусор) — как подаётся на вход. |
| `sample-report/` | Пример готового отчёта во всех форматах: `report.md`, `report.html`, `findings.csv`, `findings.json`. |

Запуск аудитора и формат вывода — в [../README.md](../README.md) и [../docs/](../docs/).
