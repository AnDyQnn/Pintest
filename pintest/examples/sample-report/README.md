# sample-report/ — пример готового отчёта

Образец вывода аудитора во **всех форматах** — чтобы видеть, как выглядит отчёт до запуска.

| Файл | Формат |
|---|---|
| `report.md` | Markdown (человекочитаемый). |
| `report.html` | HTML (для просмотра/печати). |
| `findings.csv` | CSV (таблица находок для Excel/обработки). |
| `findings.json` | JSON (машиночитаемый — его же рендерит вебка в тёмной теме). |

Сгенерировано аудитором [`../../audit.py`](../../audit.py).
