# lab — тестовое место (симуляция всей системы в Docker)

Полная имитация работы системы на одном компе: **хост** (control plane) + **3 агента** +
**уязвимые цели** в отдельной сети. Хост в эту сеть не подключён — как в реальной задаче,
он не видит цели напрямую, вся работа идёт через агентов. Отсюда удобно делать скриншоты
для отчёта.

## Что поднимается

| Контейнер | Роль | Сеть |
|-----------|------|------|
| `postgres` · `vpn` · `backend` · `frontend` | хост (control plane) | mgmt_net |
| `agent1` `agent2` `agent3` | удалённые ноды | mgmt_net + targets_net |
| `target-vsftpd` (172.30.0.11) | vsftpd 2.3.4 — CVE-2011-2523 | targets_net |
| `target-apache` (172.30.0.12) | Apache 2.4.49 — CVE-2021-41773 | targets_net |
| `target-shellshock` (172.30.0.13) | Shellshock — CVE-2014-6271 | targets_net |
| `target-oldssh` (172.30.0.14) | старый OpenSSH — находка без модуля | targets_net |
| `target-clean` (172.30.0.15) | «пропатченный» хост | targets_net |

## Запуск

```bash
bash lab/build.sh            # сборка + старт (первый раз ~5-8 мин: собирается amneziawg-go)
```
Вебка: **https://localhost:8443** · логин **admin / admin**.

Управление:
```bash
docker compose -f lab/docker-compose.yml ps            # статус
docker compose -f lab/docker-compose.yml logs -f backend
docker compose -f lab/docker-compose.yml down          # стоп (данные в lab/data сохранятся)
docker compose -f lab/docker-compose.yml down -v; rm -rf lab/data   # полностью снести
```

## Сценарий демонстрации (для скриншотов преподу)

1. **Топология.** Вкладка «Обзор» — хост в центре, нод пока нет. *(скрин 1)*

2. **Подключение агентов.** Вкладка «Агенты» → «Добавить ноду»:
   - имя `agent1`, host `agent1`, порт `22`, user `root`, пароль `pintest` → **Подключить**.
   - Повтори для `agent2`, `agent3`.
   - В логе виден provisioning: SSH → вброс AWG-ключа → туннель. На «Обзоре» ноды загораются
     зелёным, связи пульсируют. *(скрин 2 — анимированная топология)*

3. **Цели.** Вкладка «Цели» → вставь содержимое [`dirty-targets.sample.txt`](dirty-targets.sample.txt)
   → «Сохранить и почистить». Видно, как грязный список свёлся к канону (дубли/мусор убраны). *(скрин 3)*

4. **Скан.** Вкладка «Скан» → порты «топ-100», `--no-udp`, режим «параллельно» → «Запустить».
   Вкладка «Обзор»/«Отчёты» — чанки разъезжаются по агентам, отчёт растёт по ходу. *(скрин 4)*

5. **Отчёт.** Вкладка «Отчёты» → «отчёт» — интерактивный HTML с находками, CVE, CVSS.
   Можно скачать .md/.csv/.json. *(скрин 5)*

6. **Failover.** Пока идёт скан:
   ```bash
   docker stop lab-agent2-1
   ```
   Нода краснеет на топологии, её чанки перетекают на agent1/agent3, отчёт продолжается. *(скрин 6)*

7. **Self-destruct.** Отключи ноду от сети (или кнопкой «уничтожить» на вкладке «Агенты»):
   ```bash
   docker network disconnect lab_mgmt_net lab-agent3-1
   ```
   Через ~20с агент сам стирает проект и гаснет; на топологии — «уничтожен». *(скрин 7)*

8. **Эксплуатация (CTF).** Вкладка «Агенты» → назначь `agent1` роль **exploiter** (пойдёт донастройка).
   Вкладка «Эксплуатация» → выбери джобу и ноду:
   - по каждой находке с модулем нажми **check** — увидишь «✓ уязвим»;
   - отметь «подтверждаю» и нажми **закрепиться** — снимется флаг и лут (**точка захвачена**). *(скрин 8)*
   - Закрепление без галочки-подтверждения не выполняется (гейт).

9. **DIFF.** Запусти второй скан, указав «DIFF против» первой джобы → на «Отчётах» кнопка diff
   покажет новые/ушедшие CVE. *(скрин 9)*

10. **Бэкап/Обновления.** Вкладки «Бэкапы» (создать/восстановить) и «Обновления»
    (обновить хост / раскатать обновление на агентов). *(скрин 10)*

## Заметки

- Уязвимые цели — учебные эмуляции конкретных CVE (баннеры распознаёт nmap, `vulners` мапит CVE).
- `vulners` NSE тянет базу из интернета — для находок CVE нужен доступ в сеть у агентов.
- Всё строго в пределах `targets_net`. Только авторизованный стенд.
