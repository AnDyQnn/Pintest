# target: старый OpenSSH

Симуляция хоста со **старым OpenSSH** — под его баннер vulners поднимает набор CVE (Critical/High).
Служит целью со статусом «уязвима» (много находок), но **без capture-модуля** — для демонстрации
разницы «обнаружено/уязвимо» vs «обрабатываемо» в графе и отчёте.

`server.py` отдаёт старый SSH-баннер. Поднимается в `targets_net`
(см. [`../../docker-compose.yml`](../../docker-compose.yml)).
