# target: Shellshock (CVE-2014-6271)

Симуляция CGI-сервиса, уязвимого к **Shellshock**: инъекция через переменную окружения в
bash-CGI (`() { :;};`). `server.py` эмулирует уязвимый CGI-эндпоинт.

Модуль эксплуатации: [`../../../exploits/modules/shellshock.py`](../../../exploits/modules/shellshock.py).
Примечание: детект по баннеру не всегда мапится vulners на этот CVE — тогда цель в графе будет
«уязвима», но без готового модуля (это особенность детекта, не баг).
